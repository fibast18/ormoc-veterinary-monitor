ORMOC CITY VETERINARY MONITORING SYSTEM — v1.0.2

UPDATE YOUR EXISTING v1.0.1 INSTALLATION
1. Keep your existing D1 database and all its records. DO NOT re-run SQL migrations.
2. Extract this ZIP and upload/commit the complete project files to your existing GitHub `main` branch.
3. Confirm wrangler.toml has your existing D1 Database ID and no secrets are committed.
4. Check that Cloudflare Workers deploys the commit; if not run `npx wrangler deploy` in the updated folder.
5. Refresh your website and confirm footer v1.0.2.
6. Sign in as City Admin -> Users -> Create user -> Encoder. No barangay selection is needed.
7. Encoders now select ANY barangay when entering census/vaccination data or importing CSV, pending admin approval.

WARNING: All previously created Encoders automatically gain access to all 85 barangays. Review active accounts.

Read RELEASE-v1.0.2.txt and DEPLOYMENT-GUIDE.md for details.
